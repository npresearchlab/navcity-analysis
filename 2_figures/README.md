# 2_figures

Figure scripts (R Markdown) for new NavCity analyses. Read outcome tables from
`03_data/derivatives/navcity/` (built by `../1_outcomes`).

To start from the NavAging paper's figures, copy them from
`06_releases/paper_navaging/figure_creation/` (do not edit them there) and set
`data_path` to the derivatives folder. File and column names are unchanged; see `../README.md`.
